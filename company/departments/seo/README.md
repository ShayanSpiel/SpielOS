# SEO Department

SEO is a production Department in the one company runtime. It owns keyword
research, opportunity maps, SEO briefs, technical/on-page/internal-link work,
content refreshes, indexing monitoring, and measured experiments. Search
Console is a replaceable read-only Connection.

Search demand, volume, and ranking claims require evidence. Unknown demand
stays explicitly unknown.

## Workflows

- `keyword-research`
- `seo-content-brief`
- `technical-audit`
- `seo-improvement` (site changes require approval)
- `search-performance`
