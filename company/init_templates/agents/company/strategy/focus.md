# Focus doctrine — first we build, then we subtract

Every SpielOS surface — page, component, offer, email, article — follows one
workflow:

**Build. Subtract. Ship.**

Building produces meaning. Subtracting produces focus. Shipping before the
subtraction pass ships noise.

This applies to any content and any thing we do. It is not an editing style;
it is a required stage of the work.

## Why

Two rules govern every detail we allow to exist:

> "Perfect every detail, limit the number of details." — Jack Dorsey

And Alex Hormozi's value arithmetic: perceived value falls as time and effort
rise, so every extra element a visitor must read, scroll past, or decode is
friction the buyer pays for. An offer keeps only what carries the promise and
the proof.

## The subtraction test

Before any surface ships, apply to every section, paragraph, sentence, card,
icon, animation, and form field:

1. If we delete this, does the meaning change? If no — delete it.
2. Does it move the reader toward the one goal of this surface? If no — delete it.
3. Can two elements that say the same thing become one? Merge them.
4. Is the explanation longer than the idea? Cut the explanation.

Meaning must survive intact. We remove words, not claims; decoration, not
proof; repetition, not structure. A correct subtraction makes the same message
clearer, never weaker.

## Application

- **Content**: one idea per piece (see `voice.md`). Deleting sentences that do
  not strengthen the idea *is* the subtraction pass.
- **Pages**: each page has one goal and one primary call to action. Every
  section must earn its place on the path from hook to that action.
- **Offers**: fewer options beat more options. One promise, one price logic,
  one next step.
- **Design**: decoration must guide attention toward the goal; otherwise it is
  removed, not restyled.

## Enforcement

A task is not complete when the artifact exists. It is complete when the
subtraction pass has run and the result still carries the full meaning with the
fewest possible details. Reviews judge work by what was removed as well as by
what was added.
